A wearable navigation aid for blind and low-vision users, built to cost a few hundred
dollars against surgical alternatives that run into the tens of thousands. It pairs a
stereoscopic depth camera with an RGB camera and a convolutional network trained across
eighty object classes, so it names what is ahead and how far away it is at the same time.
Output reaches the user through audio on a button-driven interface, with a solenoid
tactile channel alongside it.
